# ai_bootcamp_assignment
AI Bootcamp Assignment

Prerequisites:
1. To store your OpenAI API Key in your local workspace, create a file called ".env" with the content as:
OPENAI_API_KEY={Your Open API Key}

2. Open your terminal in VS Code after loading the project into your workspace and run this command to install the necessary packages:
pip install -r requirements.txt

How to Run/Debug:
1. Open your terminal in VS Code after loading the project into your workspace and run this command to launch the Python page in streamlit (Currently the main script is app.py):
streamlit run {Your Python Script}

2. To run in Debug Mode, Select Run and Debug in your left side menu in VS Code, select the Stremlit Debug as the dropdown and click the Play button beside the Run and Debug menu. Use breakpoints just like other IDEs to pause execution and view variables.
